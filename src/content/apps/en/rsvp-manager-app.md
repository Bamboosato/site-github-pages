## Overview

Organizers create plans and events, and invitees submit attendance responses. An organizer interface shows response status and supports invitation-link sharing.

## Key features

- Plan/event creation and response management
- Invite-link response flow and PIN reset
- Response-update notifications and PWA support

## Design and usage

Firebase supports organizer authentication and data storage. Separate organizer and invitee flows help share attendance status.

## Technologies

Next.js, TypeScript, Firebase Authentication, Firestore, and Firebase Cloud Messaging support the app.
